# Message Fold and Delete

A SillyTavern extension that lets you fold long messages into a single bar and delete messages with a long press.
긴 메시지를 한 줄 바로 접고, 길게 눌러서 삭제할 수 있는 SillyTavern 확장입니다.


## Features
- **Fold / Unfold** – Click the fold icon in a message's action buttons to collapse it into a slim bar. 
- **Peek** – Tap a folded bar to open it temporarily. Tap elsewhere and it folds again. (To fully restore the message, click the uncollapse icon again)
- **Long press menu** – Press and hold a message to get a popup: **Delete**, **Fold / Unfold**, or **Cancel**. The delete option works almost the same as SillyTavern's built-in "Delete this message", but it's more convenient: you don't need to open the edit window first.

- **접기 / 펼치기** – 메시지 액션 버튼의 접기 아이콘을 누르면 메세지가 얇게 접힙니다. 
- **미리보기** – 접힌 바를 누르면 임시로 펼쳐지고, 다른 곳을 누르면 다시 접힌 상태로 되돌아옵니다. (접힌 상태를 완전히 해제하려면 해제 아이콘을 다시 누르세요)
- **길게 누르기 메뉴** – 메시지를 길게 누르면 팝업이 뜹니다. : **Delete(삭제)**, **Fold / Unfold(접기/펼치기)**, **Cancel(취소)**. 삭제 기능은 실리태번 기본 "Delete this message"와 거의 같지만, 편집창을 일일이 켜지 않아도 돼서 조금 더 편리합니다.
