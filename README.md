# Message Fold and Delete

A SillyTavern extension that lets you fold long messages into a single bar and delete messages with a long press.

## Features
- **Fold / Unfold** – Click the fold icon in a message's action buttons to collapse it into a slim bar. The folded state is saved with the chat.
- **Peek** – Tap a folded bar to open it temporarily. Tap elsewhere and it folds again.
- **Long press menu** – Press and hold a message to get a popup: **Delete**, **Fold / Unfold**, or **Cancel**.

## 기능
- **접기 / 펼치기** – 메시지 액션 버튼의 접기 아이콘을 누르면 얇은 바로 접혀요. 접힌 상태는 채팅에 저장돼요.
- **미리보기** – 접힌 바를 누르면 임시로 펼쳐지고, 다른 곳을 누르면 다시 접혀요.
- **길게 누르기 메뉴** – 메시지를 길게 누르면 팝업이 떠요: **Delete(삭제)**, **Fold / Unfold(접기/펼치기)**, **Cancel(취소)**.
